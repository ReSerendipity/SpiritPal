## 三、回填流程（用户侧）

1. **分类**：把 90 个角色按「IP 衍生 / 原创」分组（可从 `zh` 名与 `src/lib/data/characters.ts`
   的 profile 判断；IP 衍生角色多为鸣潮/胜志 etc. 二创，原创角色为 Doro 系）。
2. **定名**：
   - IP 衍生 → 采用官方/社区通行 localized 名（鸣潮国际服、日服官方译名等）；
   - 原创 → 产品确认命名（罗马音/英文转写或既定英文名）。
3. **填写** CSV 四列 → 回填 `src/lib/system/i18n.ts` 的 en/ja/ko/zhTw 四个语言块
   （在各自的 `'char.doro'` 行附近按 key 对齐插入即可；注意**单花括号**插值约定，角色名无参不受影响）。
4. **转严格**：从 `src/lib/system/__tests__/i18n-completeness.test.ts:53` 的
   `KNOWN_DEBT_PREFIXES = ['char.']` 中移除 `'char.'`。
5. **验证**：
   ```bash
   npx vitest run src/lib/system/__tests__/i18n-completeness.test.ts   # 五语言键集守卫转严后仍全绿
   grep -c "'char\." src/lib/system/i18n.ts                            # 每语言块应各 90
   ```
   模拟器切 en/ja/ko 走查：角色列表/当前角色显示名/升级浮层/相册 无中文名残留。
6. 保留 `characters.ts` 的 `defaultValue: profile.displayName` 兜底（工单要求不删）。

## 四、机制现状（已核验）

- 回退链：`characters.ts:41 withLocalizedName()` → `t('char.<id>', { defaultValue: displayName })`
  → 字典缺失时回退原名，**任何语言不崩溃、只显示中文**（当前状态）。
- 守卫：`i18n-completeness.test.ts` 对非 `char.` 前缀键已是严格模式（缺失/多余都报）；
  `char.` 在 `KNOWN_DEBT_PREFIXES` 豁免中，回填完成后移除即转严。
