## 🗑️ 任务移除说明

以下任务已于 2026-08-13 从项目规划中**正式移除**：

### 1. macOS NSPanel 浮层（参考 BongoCat）
**移除原因**:
- 需引入 `tauri-nspanel` 私有 API
- 与 macOS 系统版本兼容性需独立测试
- 与项目主要目标平台（Windows）偏离

### 2. 双向流式推理（参考 CosyVoice v3）
**移除原因**:
- 需要 LLM 引擎原生支持双向流
- 当前引擎仅支持单向流，重构成本高

### 3. Cognee 知识图谱集成
**移除原因**:
- 第三方服务需独立部署评估
- 作为 vectorSearch 增强方案成本高

### 4. CRDT 实时协同（参考 AppFlowy）
**移除原因**:
- simple-yjs 1.0.0 Kotlin 绑定不存在于 Maven Central
- 与主项目定位（桌面宠物）偏离
- 实施成本高
