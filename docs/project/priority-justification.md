## 优先级调整规则

1. **Must → Should**：Must 项验收不通过（如 A1 失效无降级方案）时，该 Must 项降级为 Should 并启动降级方案
2. **Should → Must**：竞品在 Should 项上形成差异化优势时，升级为 Must
3. **Could → Should**：用户反馈数据显示 Could 项有高需求时，升级
4. **任何变更**：必须填写变更评估表（见 `change-management.md`），记录调整原因
