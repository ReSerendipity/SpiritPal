# SpiritPal STRIDE 威胁建模报告

**建模日期**: 2026-08-26  
**版本**: v0.1.0  
**方法论**: STRIDE (Spoofing / Tampering / Repudiation / Information Disclosure / Denial of Service / Elevation of Privilege)

---

## 1. 系统架构边界

SpiritPal 是一款 Tauri 2.x 桌面宠物应用，核心信任边界：

```
┌──────────────────────────────────────────────────────┐
│                    用户设备                              │
│  ┌─────────────┐    IPC    ┌──────────────────┐        │
│  │  WebView      │◄────────►│   Rust 后端         │        │
│  │  (React 前端) │           │  (Tauri Runtime)  │        │
│  │              │           │                   │        │
│  │ 3 个窗口:    │           │ - 加密/解密        │        │
│  │ pet-window   │           │ - SQLite           │        │
│  │ chat-window  │           │ - 文件系统          │        │
│  │ settings-win │           │ - 系统 Keychain    │        │
│  └──────┬───────┘           └────────┬──────────┘        │
│         │                            │                   │
│         ▼                            ▼                   │
│  ┌──────────────────────────────────────────────┐        │
│  │        本地文件系统 / localStorage / SQLite      │        │
│  └──────────────────────────────────────────────┘        │
│         │                                                │
└─────────┼────────────────────────────────────────────────┘
          │ HTTPS
          ▼
   ┌──────────────────┐
   │  外部 LLM API     │
   │  (OpenAI/Claude  │
   │   /DeepSeek 等)  │
   └──────────────────┘
```

## 2. 威胁清单

| S-1 | 仿冒 LLM API 端点劫持 API Key | API Key | 高 | HTTPS 强制 + 系统 Keychain 存储 Key（不落盘明文） | ✅ 已缓解 |
| S-2 | 仿冒更新源推送恶意更新 | 安装包 | 中 | Tauri Updater Ed25519 签名验证（pubkey 已配置） | ✅ 已缓解 |
