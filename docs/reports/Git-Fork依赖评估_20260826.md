# Git Fork 依赖评估报告

**评估日期**: 2026-08-26  
**评估范围**: 使用 git fork/branch 而非 registry 版本的依赖

---

## 评估的依赖

### 1. `rdev` (Rust)

- **当前配置**: `rdev = { git = "https://github.com/kunkunsh/rdev" }`
- **用途**: 全局键鼠监听（宠物注视光标效果，参考 BongoCat）
- **风险评估**:
  - **可变性风险**: git 仓库可能被删除 / 强制推送 / 分支变更
  - **供应链风险**: fork 作者可能注入恶意代码
  - **可审计性**: 无固定 commit hash，每次 cargo update 可能拉取不同代码
- **缓解措施**:
  - ✅ `Cargo.lock` 锁定具体 commit（构建可复现）
  - ⚠️ 但 `cargo update` 会拉取最新 commit，缺乏锁定 commit 的声明式配置
- **建议**:
  - 短期：将 git fork 改为指定 commit/tag：`rdev = { git = "https://github.com/kunkunsh/rdev", rev = "<specific-commit>" }`
  - 中期：评估是否可使用 registry 版本（crates.io 上的 rdev）或自行 fork + tag
  - 长期：将该功能实现为独立模块，减少对 fork 的依赖

### 2. `tauri-nspanel` (Rust, macOS only)

- **当前配置**: `tauri-nspanel = { git = "https://github.com/ahkohd/tauri-nspanel", branch = "v2.1" }`
- **用途**: macOS NSPanel 浮层（宠物窗口跨 Space / 全屏可见）
- **风险评估**:
  - **可变性风险**: branch 引用可能被删除 / 强制推送
  - **平台限制**: 仅 macOS 编译时引入
- **缓解措施**:
  - ✅ `Cargo.lock` 锁定具体 commit
  - ✅ 仅 macOS 平台引入（影响范围有限）
- **建议**:
  - 短期：将 branch 改为指定 tag/rev
  - 中期：跟踪上游是否有 registry 发布计划

---

## 结论

| 依赖 | 风险 | 当前缓解 | 待改进 |
|------|------|---------|--------|
| rdev (git fork) | 中 | Cargo.lock 锁定 | 改用 rev 指定 commit |
| tauri-nspanel (git branch) | 低 | Cargo.lock + 仅 macOS | 改用 rev 指定 commit |

当前两个 git fork 依赖的风险**可接受**（Cargo.lock 提供构建可复现性），但建议在下一个版本中改为指定 commit hash（`rev = "..."`）以增强供应链可审计性。
