- **分支策略**：日常只在 `main`（本地）提交；对外发布合并到 `public` 后 `push origin public`。
  **绝对禁止 `git push origin main`**（会泄漏本地私有代码到 GitHub）。
- **不碰自我进化文档**：`docs/project/KNOWN_GOTCHAS.md`、`docs/project/REVISION_LOG.md`
  由专门流程维护，普通会话不要编辑（即便实施计划第 236 行要求同步，也归该流程负责）。
- **禁止假实现 / 诚实降级**：做不到的部分显式降级为文档化设计稿或纯 CSS 兜底，
  绝不能写占位 TODO 假装实现（AGENTS.md 铁律 #6）。
- **perf 数据本地不入库**：`perf/results/*.json` 与 `*.html` 是 `pnpm perf:trend` /
  `perf:memory-recall` 的再生产物，已 gitignore；趋势源 `recall-history.json` 等也不入库。
- **评测边界要知道**：记忆召回评测在 mock 下短路了向量检索 / RAG，纯本地无法补 case 20；
  真实 RAG 接通后该 case 自然命中。
