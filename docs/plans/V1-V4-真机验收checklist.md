## 0. 自动化预处理（发版前先跑，人工验收以此为准）

| 项目 | 命令 | 通过线 | 产物 |
|------|------|--------|------|
| 全量单测 | `pnpm test:unit` | 0 fail | — |
| 性能四项 | `node perf/run-all.mjs` | 全 PASS | `perf/results/perf-run-latest.json` |
| ├─ 冷启动 | `cold-start.mjs` | `< 2000ms` | `perf/results/cold-start.json` |
| ├─ 内存 | `memory-usage.mjs` | `< 80MB` | `perf/results/memory-usage.json` |
| ├─ Live2D 帧率 | `fps-test.mjs` 🤖 | `≥ 30fps` | `perf/results/fps-test.json` |
| ├─ 拖拽帧率 | `drag-fps.mjs` 🤖(B-4 新增) | `≥ 30fps` | `perf/results/drag-fps.json` |
| └─ 安装包 | `package-size.mjs` | `< 30MB` | `perf/results/package-size.json` |
| 记忆检索 P95 | `src/lib/__tests__/memoryRecall.bench.test.ts` 🤖 | P95 `< 100ms` | `perf/results/memory-recall-p95.json` |
| 记忆召回评测 | `src/lib/__tests__/memoryRecall.eval.test.ts` 🤖 | Top-5 命中 `≥ 70%` | 控制台输出命中率 |

> ⚠️ **关于帧率基准的诚实说明**：`fps-test` / `drag-fps` 测的是 **webview 渲染层**帧率
> （Playwright + swiftshader 软件渲染），不含真实 Tauri 窗口拖动时 Rust 侧
> `outerPosition/setPosition` 开销，也非真机 GPU 表现。它们是**回归保护线**，真机手感需
> 人工在 V1 阶段实测确认。
