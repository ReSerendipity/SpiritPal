# Sentry 错误监控集成指南

## 一、快速开始\n\n### 1. 创建 Sentry 项目\n\n1. 访问 [sentry.io](https://sentry.io/) 并注册/登录\n2. 创建新项目：\n   - 选择 **JavaScript** → **React + Tauri**\n   - 项目名称：`spiritpal-app`\n3. 获取 DSN：项目 Settings → Client Keys (DSN)\n\n### 2. 安装 Sentry SDK\n\n```bash\n# 开发环境 (可选，仅用于本地测试)\nnpm install @sentry/react\n\n# 生产环境推荐使用离线兼容方案 (见下文)\n```\n\n### 3. 配置环境变量\n\n创建 `.env.production`:\n\n```env\nVITE_SENTRY_DSN=https://your-public-dsn@sentry.io/your-project-id\nVITE_SENTRY_ENVIRONMENT=production\nVITE_SENTRY_RELEASE=v1.0.0\nVITE_SENTRY_TRACES_SAMPLE_RATE=0.1\n```\n\n### 4. 初始化 Sentry\n\n修改 `src/main.tsx` (已有 Mock 实现，可替换为真实 SDK):\n\n```tsx\nimport { sentry, setupGlobalErrorListeners } from './lib/sentry';\n\n// 读取环境变量\nconst isProd = import.meta.env.PROD;\nconst dsn = import.meta.env.VITE_SENTRY_DSN;\n\nif (dsn && isProd) {\n  // 真实 SDK 初始化 (取消注释并安装 @sentry/react)\n  // import('@sentry/react').then(({ init, reactErrorHandler }) => {\n  //   init({\n  //     dsn,\n  //     environment: import.meta.env.VITE_SENTRY_ENVIRONMENT || 'production',\n  //     release: import.meta.env.VITE_SENTRY_RELEASE,\n  //     integrations: [\n  //       new BrowserTracing(),\n  //       new Replay(),\n  //     ],\n  //     tracesSampleRate: parseFloat(import.meta.env.VITE_SENTRY_TRACES_SAMPLE_RATE || '0.1'),\n  //     replaysSessionSampleRate: 0.1,\n  //     replaysOnErrorSampleRate: 1.0,\n  //   });\n  // });\n}\n\n// 启用全局错误监听\nsetupGlobalErrorListeners();\n```\n\n### 5. 使用示例\n\n#### 捕获异常\n\n```tsx\nimport { sentry } from './lib/sentry';\n\ntry {\n  await someRiskyOperation();\n} catch (error) {\n  sentry.captureException(error, {\n    operation: 'someRiskyOperation',\n    userId: currentUser.id,\n  });\n  throw error; // 重新抛出让 UI 也能处理\n}\n```\n\n#### 添加面包屑\n\n```tsx\nimport { addAppBreadcrumb } from './lib/sentry';\n\naddAppBreadcrumb('navigation', '用户切换到记忆页面', { \n  previousPage: '/settings' \n});\n```\n\n#### 用户识别\n\n```tsx\nimport { identifyUser, clearUserContext } from './lib/sentry';\n\n// 登录后\nidentifyUser('user_123', 'user@example.com', '张三');\n\n// 登出时\nclearUserContext();\n```\n\n---\n\n## 二、生产环境部署方案\n\n### 方案 A: 官方 CDN 方式 (推荐，零构建改动)\n\n```html\n<!-- 在 index.html 中添加 -->\n<script src=\"https://browser.sentry-cdn.com/7.97.0/bundle.min.js\" integrity=\"sha384-...\" crossorigin=\"anonymous\"></script>\n<script>\n  Sentry.init({\n    dsn: '{{VITE_SENTRY_DSN}}',\n    // 其他配置...\n  });\n</script>\n```\n\n**优点**: \n- 无需 npm 安装\n- 自动缓存 CDN 资源\n- 不影响打包大小\n\n**缺点**:\n- 依赖外部网络\n\n### 方案 B: 内嵌 SDK (完全离线)\n\n1. 下载 SDK bundle: `wget https://browser.sentry-cdn.com/7.97.0/bundle.min.js`\n2. 放入 `public/sentry/`\n3. 在 `index.html` 引用本地文件\n\n### 方案 C: NPM 集成 (完整功能)\n\n```bash\nnpm install @sentry/react @sentry/vite-plugin\n```\n\n在 `vite.config.ts` 添加插件:\n\n```ts\nimport * as Sentry from '@sentry/vite-plugin';\n\nexport default defineConfig({\n  plugins: [\n    Sentry.vitePlugin({\n      org: process.env.SENTRY_ORG,\n      project: process.env.SENTRY_PROJECT,\n      authToken: process.env.SENTRY_AUTH_TOKEN,\n    }),\n  ],\n});\n```\n\n---\n\n## 三、Tauri 特定注意事项\n\n### 1. 捕获 Rust 层错误\n\n在 `src-tauri/src/lib.rs` 中添加错误日志钩子:\n\n```rust\nuse std::io::{Write};\n\n#[tauri::command]\nfn log_frontend_error(message: String, error: String) {\n  eprintln!('[Frontend Error] {}\\n{}', message, error);\n  // 可选：发送到后端持久化或报警系统\n}\n```\n\n### 2. 性能追踪限制\n\nTauri WebView 性能与浏览器略有差异，建议:\n- 关闭复杂的面板分析 (减少内存占用)\n- 仅保留错误追踪 + 基础性能指标\n\n---\n\n## 四、监控指标说明\n\n### 错误类型\n\n| 类型 | 说明 |\n|------|------|\n| JavaScript Error | 运行时异常、未捕获的 Promise rejection |\n| React Error | 组件渲染错误、Hook 异常 |\n| Resource Error | 图片加载失败、API 请求失败 |\n| Network Error | WebSocket 断开、HTTP 4xx/5xx |\n\n### 性能指标\n\n| 指标 | 阈值 |\n|------|------|\n| 冷启动时间 | < 2s |\n| 模型切换延迟 | < 500ms |\n| FPS | ≥ 30 |\n| 内存占用 | < 80MB |\n\n---\n\n## 五、查看和分析\n\n### 访问仪表盘\n\n1. 登录 [sentry.io](https://sentry.io/issues/)\n2. 选择项目 → Issues\n3. 按频率/影响范围排序优先级\n\n### 典型工作流\n\n1. **收到报告** → 复现问题\n2. **查看详情** → 检查堆栈、用户行为路径 (Breadcrumbs)\n3. **修复代码** → 提交 commit (包含 `Fixes #ISSUE_NUMBER`)\n4. **验证修复** → 观察新版本发布后的错误率变化\n\n---\n\n## 六、隐私和安全\n\n### 敏感数据处理\n\n1. **不要上传**:\n   - 用户密码/密钥\n   - 身份证号、银行卡等 PII\n   - 内部 IP 地址\n\n2. **建议使用**:\n   - 事件过滤钩子 (`beforeSend`)\n   - 数据脱敏 middleware\n   \n示例:\n\n```ts\ninit({\n  beforeSend(event) {\n    if (event.user?.email?.includes('@internal')) {\n      return null; // 不发送内部员工数据\n    }\n    return event;\n  },\n});\n```\n\n### GDPR 合规\n\n- 在隐私政策中说明使用 Sentry\n- 提供用户拒绝追踪的选项\n- 定期清理过期数据\n\n---\n\n## 七、故障排查\n\n### 常见问题\n\n**Q: Sentry 未发送数据**\n- 检查 DSN 是否正确\n- 确认环境变量已加载\n- 查看控制台是否有 CORS 错误\n\n**Q: 堆栈跟踪不完整**\n- 确保开启了 source maps\n- Release 构建时保留 debug id\n\n**Q: 内存占用过高**\n- 降低 `tracesSampleRate`\n- 关闭 session replay (非必需)\n\n---\n\n## 附录：当前实现状态\n\n✅ **已完成**:\n- Mock Sentry 实现 (开发环境可用)\n- 全局错误监听器\n- 用户上下文管理\n- 面包屑系统\n- 文档指南\n\n⏳
