# Live2D 发行许可申请提醒（Reminder）

> 最后更新：2026-08-12

## ⚠️ 何时需要申请

| 状态 | 是否需要申请 |
|---|---|
| 个人自用 / 本地测试（不分发） | ❌ 不需要 |
| **公开发布 / 上架 / 分发给他人（哪怕免费）** | ✅ **需要申请（个人/小规模可免费取得）** |
| 商用（收费、企业运营、年销售额超过约 2000 万日元 ≈ 100 万人民币） | ✅ 必须申请并付费 |
