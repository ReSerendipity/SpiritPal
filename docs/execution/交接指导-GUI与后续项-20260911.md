**目标**：把 `perf/model-switch-latency.mjs` 的「模拟延迟 301ms（sleep(300)）」替换为**真实触发**的测量值；PRD v0.2 阈值 **< 500ms**。

**现状**：
- 脚本 `C:\Users\Doro\SpiritPal\perf\model-switch-latency.mjs` L93-95：`await sleep(300) // 模拟切换操作本身的时间` + TODO「集成 Tauri 命令调用」

- 上一轮实测 301ms 为模拟值，已记录（RELEASE_VERIFICATION.md 四章注明）

**阻塞（已确认）**：
1. GUI 自动化无管理员权限（虚拟桌面 PIP 初始化失败）
2. WebView2 CDP 调试端口未开启（9222/9223 无监听）——release 构建无调试通道

**可执行路径（按优先级）**：
1. **获得管理员权限后用 GUI 驱动**（最贴近真实用户操作）：
