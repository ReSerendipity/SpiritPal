## 5. 自主决策记录（关键项）

| 决策 | 依据 | 理由 |
|---|---|---|
| PASSWORD secret 不设置 | 私钥无密码实测 + GitHub Actions 未设置 secret 解析为空串 | 与空密码签名行为一致；多一个空值 secret 无增益 |
| 私钥备份降级为用户文档目录 | 本机无可访问外部保险库 | SOP-17 精神（离线备份 + 恢复说明 + 哈希校验）以可落地方式达成 |
| P2-1 "未消费即失效"降级为双校验 | capability 权限标识符与 invoke 命令名无一一映射 | 改为"插件实现存在 + invoke 命令已注册"反向校验，守住最小授权实质 |
| 崩溃自启采用受限自动重启（60s 冷却 + 上限 3 次） | 任务书"若无则补" | 最小实现、无新依赖、可禁用（环境变量）、防无限循环 |
| 提交采用 Conventional Commits、main 直推 | 项目既有 git 历史确认 | 与仓库约定一致 |
| 远程新增 dependabot 提交 → `git pull --rebase` | 禁止 force push / 改写远端历史 | 线性重放、无冲突、保留双方工作 |
