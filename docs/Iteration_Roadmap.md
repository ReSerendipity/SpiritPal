# SpiritPal 后续迭代方向规划

## 二、功能迭代路线图

### 2.1 核心功能

#### 2.1.1 宠物系统
- **当前状态**：基础宠物显示和交互
- **短期目标**：优化动画效果，添加更多互动
- **中期目标**：实现3D模型支持，添加物理效果
- **长期目标**：支持VRM模型，实现动作捕捉

#### 2.1.3 养成系统

- **短期目标**：优化数值平衡，添加更多物品
- **中期目标**：实现任务系统，添加成就系统
- **长期目标**：实现社交系统，添加排行榜
