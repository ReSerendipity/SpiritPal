## 四、缺失要素清单（按优先级）

### 🟡 中优先级（本月内完成）

| # | 缺失项 | 优先级 | 建议位置 | 说明 |
|---|--------|:------:|----------|------|
| 1 | **install.bat + start.bat** | 🟡 高 | 项目根目录 | 作为一个 Windows 桌面应用，用户不应手动敲 `pnpm install` 和 `pnpm tauri dev`。参考 Seedvr2 / TTS_MultiModel 的 bat 脚本，写两个一键脚本：<br>• **install.bat**：自动检查 pnpm/node，不存在则提示安装，然后执行 `pnpm install`<br>• **start.bat**：自动执行 `pnpm tauri dev`，并在启动后等待浏览器/窗口打开 |
| 2 | **CHANGELOG.md** | 🟡 中 | 项目根目录 | 虽然是闭源，但记录每次版本改了什么对自己很有用。第一版可以简单写：<br>```<br># Changelog<br>## v0.1.0 (2026-08-10)<br>- 项目初始化发布<br>- 实现桌面宠物核心功能<br>- 支持记忆系统与多角色<br>``` |
| 3 | **辅助脚本扩充 scripts/** | 🟡 中 | scripts/ 目录 | 可以补几个实用脚本：<br>• **build-release.bat**：一键执行 `pnpm tauri build` 生成安装包<br>• **run-all-tests.bat**：一键跑 vitest + playwright + cargo test<br>• **generate-icons.bat**：如果需要重新生成图标素材时使用 |

### 🔵 低优先级（有空再做）

| # | 缺失项 | 优先级 | 建议位置 | 说明 |
|---|--------|:------:|----------|------|

## 六、总结

SpiritPal 是 5 个项目中**基础设施最完善的一个**，测试体系（尤其是性能测试）做得比很多商业项目还好。作为闭源项目，目前**没有必须补的 P0 级大坑**，缺失的都是一些"让自己以后更省事"的脚本和文档。

**最大的收获点**：补两个 bat 脚本后，你就能和其他 3 个 Python 项目一样，双击就能运行，不用每次开终端敲命令了。
