# SpiritPal 性能监控计划

## 📊 监控指标
- **启动时间**: 应用从点击到界面可交互的耗时
- **内存占用**: 峰值 RSS（Resident Set Size）
- **CPU 使用率**: 空闲状态下的 CPU 百分比
- **错误数**: 启动过程中的异常计数

## 🚀 使用方法
`ash
cd C:\Users\Doro\SpiritPal
python perf_monitor.py
`

## 📁 输出位置
结果保存在 ./perf/results/benchmark_YYYYMMDD_HHMMSS.json

## 📋 执行建议
- **频率**: 每周手动运行一次即可
- **时机**: 在重大代码变更后运行
- **记录**: 将结果与基线对比，关注趋势变化

## ⚠️ 注意事项
- 不需要设置定时任务，根据实际需要手动运行
- 确保关闭其他占用大量资源的程序
- 建议在开发环境中测试，而非生产环境
